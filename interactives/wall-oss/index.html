WALL-OSS：一个 VLM 怎样长出动作

一共 11 幕。第 1 幕是总览（它输出什么，不输出什么）；第 2 到 4 幕是结构（三种耦合范式、一层里的共享注意力和两个 FFN、token 序列和注意力掩码）；第 5 到 8 幕是训练和推理（FAST 离散化、融合阶段冻结谁、流匹配训练、采样步数）；第 9 幕是 Uni-CoT；第 10、11 幕是数据配方和结果。

每一幕自动循环。可以暂停、拖进度条、拖动画面旋转、滚轮缩放，第 1 幕的方块可以点。大多数幕左上角有开关。层宽、词表、参数量来自 HF 权重 x-square-robot/wall-oss-flow 的配置和文件头；路由、掩码、冻结、流匹配细节来自 wall-x 论文时期的提交 86f70a3；第 11 幕是原文图 7 的矢量读数和表 2。第 5、7、8 幕的数字是页面当场算的玩具。没有任何模型在这里运行。

11 幕

点一行跳到那一幕。不开 WebGL 时，这里和右侧的文字一样能读。

    完整结构：每个部件和每一步

    “论文”和“代码”分开写。代码是 X-Square-Robot/wall-x 提交 86f70a3（2025-09-11，arXiv v1 之前最后一个），只读未运行，Apache-2.0；HF 指 x-square-robot/wall-oss-flow 的 config.json 和 safetensors 文件头。

    #部件论文代码 / HF
    输入
    I1视觉第一人称和腕部相机Qwen2.5-VL 视觉塔，32 层、1280 维，合并后 2048 维；示例分辨率 256
    I2文本指令（可含子任务）“Observation: … Instruction: … Predict the next action in robot action / language.”
    I3机器人状态图 3 的 Robot State一个 <|propri|> token，嵌入 = propri_proj([状态 20, 掩码 20])，2048 维
    I4加噪动作Integration 阶段的 Noise32 个 <|action|>，嵌入 = w3(SiLU(w2([w1([动作 20, 掩码 20]), 时间嵌入])))
    主干
    B1层数Qwen2.5-VL-3B36 层，隐藏 2048，16 个查询头、2 个 KV 头
    B2注意力共享共享；因果，动作 token 之间双向
    B3VL FFN继承自 VLMSwiGLU，中间维 11008，36 层共 24.3 亿
    B4动作 FFN新加SwiGLU，中间维 2048，36 层共 4.53 亿
    B5路由静态，不是 top-ktoken_type = (id == <|action|>)；状态、FAST token 走 VL FFN
    输出
    O1文本CoT、子任务（LM 头）lm_head，词表 153,715 行（含 2048 个 FAST token）
    O2离散动作FAST：DCT → 量化 → BPEphysical-intelligence/fast，scale 10，2048 个 token
    O3连续动作流头，式 (2)action_proj_back 2048 → 20；32 步一块
    O4未来画面不输出没有解码器
    训练
    T1Inspiration具身 VQA + FAST，式 (1)一个交叉熵，没有 λ_VQA / λ_D；预训练代码未公开
    T2Integration 1冻结 VLM，只训流头freeze_vlm：只训 moe.experts.1，流头投影也冻结
    T3Integration 2全部解冻AdamW wd 0.1，余弦学习率
    T4流匹配x_t = (1−ρ)x₀ + ρε，目标 ε − x₀x_t = (1−t)ε + t·a，目标 a − ε，t = (0.999 − u)/0.999，u ~ Beta(1.5, 1)
    T5采样没写Euler，linspace(0, 1, 10) → 9 步（之后修成 10 步）
    T6Uni-CoT指令 → CoT → 子任务 → 动作，路径丢弃两种样本：子任务生成 / 以子任务为指令出动作；默认比例 0

    哪些是示意

    • 第 1、2 幕的方块和流动的小球。只是示意结构，36 层画成 12 片。
    • 第 3 幕。16 个 token 的种类和顺序是我挑的；FFN 方块的宽度按中间维的比例（11008 : 2048）画。
    • 第 4 幕。32 个动作 token 和几百个图像 token 都画成几个格子；掩码规则按代码当场算。
    • 第 5 幕。那条动作曲线是我设的玩具；DCT、×10 量化当场算；“BPE”只示意合并，没有跑真的 BPE。
    • 第 7 幕。二维“动作分布”是我设的两团高斯；时间的直方图按代码的采样公式用固定种子抽 4000 次。
    • 第 8 幕。噪声和目标动作块是玩具；假设学到的速度场恰好是直线路径的速度，所以只示意步数，不示意误差。
    • 第 10 幕。24 个小方块代表表 1 的 24 个开源数据集，不按大小。
    • 第 11 幕。柱高是原文图 7 的矢量读数（重画），表 2 照录。
