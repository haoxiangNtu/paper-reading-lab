    #部件原论文（S-VAE / PS-VAE）OpenWAM 的 S-VAE
    输入
    I1图像 / 视频224 × 224 中心裁切（ImageNet-1K）9 帧 384 × 320（RoboTwin），按 1 + 4 + 4 时间平均成 3 个隐帧
    I2表示编码器DINOv2-B，patch 14 → 16 × 16 × 768；PS-VAE 阶段解冻DINOv3 ViT-B/16（768）或 V-JEPA 2.1 ViT-g/16（1408），冻结 → (B, D, 3, 24, 20)
    I3标准化未提按数据集统计的逐通道均值和标准差（stats.pt）
    语义编解码器
    E1编码器 Eₛ3 个继承自表示编码器的 Transformer 块 + MLP 投影3 个 pre-LN 块（宽 D，16 头，FFN 2048）→ LayerNorm → Linear(D, 2×48)
    E2注意力范围一张图的 256 个 token（推断）每个隐帧的 480 个 token
    E3隐变量96 通道（另有 32），KL 正则48 通道，KL 正则；用的时候只取 μ
    E4解码器 Dₛ对称：MLP 投影 + 3 块Linear(48, D) → 3 块 → LayerNorm → 反标准化
    E5参数量未给；若用 DINOv2-B 形状的块，约 42.8M（我的估算）D = 768：33.2M；D = 1408：82.5M（我按代码算）
    损失和训练
    L1语义重建ℓ₂ + 余弦，相对权重未给MSE + 1 ×（1 − cos），逐 token
    L2KLLDM 式，权重未给β = 1e-4，前 20% 步线性升起
    L3像素S-VAE：像素解码器只为评估，输入 detach；PS-VAE：联合，权重 0.1没有像素解码器
    L4优化batch 96，lr 1e-4，两阶段AdamW，lr 1e-4，batch 8 片段，50 轮，余弦到 0.9 倍，bf16
    下游
    G1生成模型Transfusion 式共享块，Qwen2.5-0.5B 初始化，宽 DDT 头（653M）；扩展到 1.5B、3BWan2.2-TI2V-5B 结构的 DiT，随机初始化，宽 3072
    G2进入生成模型前2D 位置编码，时间步注入初始隐状态按 token 的 LayerNorm，再 Conv3d(48, 3072, 1×2×2)，每 token 192 维
    G3噪声 shift训练 s = √(C·P²/16)：96c 为 2.449；推理统一 3shift = 5，对所有编码器相同
    G4输出像素解码器出 256 × 256 图只预测 48 维隐帧，不解码

    哪些是示意

    • 第 2 幕的点云。“PS”字形是我手写的折线采样，三维里的离面漂移是我设的噪声，只说明“多出来的维度让样本离开平面”。论文的玩具实验是 2 维对 8 维、256 通道 MLP，这里没有重跑。
    • 第 3 幕的式 (1)。数据集是第 2 幕的 400 个点，嵌入三维（l = 2，h = 3）；两边的速度都按有限数据集的精确后验当场算，差值读数是真的。这是玩具，不是 DINOv2。
    • 第 3 幕的“噪声占比”。(h − l)/(h + l) 假设数据在每个内在维度上方差为 1，只是量级示意。
    • 第 6 幕的向量。两个 8 维向量和它们的 ℓ₂、余弦是当场算的玩具，KL 也是对一个玩具高斯算的。
    • 方块的大小。按维度的对数缩放，不是参数量。
